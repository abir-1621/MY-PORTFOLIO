Friends and Fund: accurate records for group savings

I built a private savings and deposit platform for trusted friend groups, replacing scattered records with secure member access, clear approvals, and a consistent monthly process.

01 / Context

Shared money requires clear records and clear permissions.

Friend-based savings groups need to track members, shares, monthly deposits, receipts, and approvals. When that information lives across spreadsheets and chat messages, it becomes difficult to confirm the current state or trace an earlier decision.

The product needed separate admin and member workflows without exposing information or controls to the wrong person.

02 / Approach

Put financial rules on the server.

I built the application in Next.js and TypeScript, with Supabase Auth and PostgreSQL behind it. Deposit amounts are calculated on the server, which keeps the monthly contribution rules consistent instead of relying on values supplied by the browser.

  • Role-based access: admin and member actions are separated through authentication and Row Level Security.
  • Approval workflow: members upload receipts and admins review deposits before approval.
  • Audit history: important changes leave a record that can be reviewed later.
  • Monthly reporting: the dashboard brings member accounts, shares, deposits, and payment status into one view.

03 / Product result

One source for the group's monthly process

One dashboardfor member accounts, shares, deposits, and receipts
Server-calculateddeposit amounts based on the product's financial rules
Traceableapprovals and audit logs for financial actions

The result is a cleaner separation between the group's financial rules, the records stored in the database, and the interface each role uses.

04 / Engineering lesson

Trust depends on predictable system behavior.

Financial software has to make permissions and calculations explicit. Moving sensitive rules to the server and enforcing access in the database reduced the number of places where the application could produce an inconsistent result.
