# Repository instructions

Before creating or editing any visual or written asset that represents Md Abir, read and follow `BRAND_GUIDELINES.md` and `brand-tokens.json`.

These files govern websites, social-media cards, project thumbnails, presentation covers, profile banners, diagrams, and personal-brand copy. Keep personal branding separate from employer or partner branding. Never invent roles, dates, metrics, clients, testimonials, or project outcomes.

For portfolio content, keep `index.html`, `js/portfolio-data.js`, structured data, and related project pages consistent when the same fact appears in more than one place.
